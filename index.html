🔄

Incompatible Slots

DDR3 / DDR4 / DDR5 have different physical notch positions. You physically cannot insert wrong DDR into a motherboard — no risk of damage, just won't fit.

⚡

Dual Channel = ~20% Speed Boost

2×8GB is always better than 1×16GB. Use matching slots (usually A2 + B2, check your motherboard manual). Same brand, same speed preferred.

⚙️

Enable XMP / EXPO in BIOS

RAM defaults to slow 2133MHz. Enable XMP (Intel) or EXPO (AMD) in BIOS to get rated speed. Takes 30 seconds — always do this!

📦

16GB vs 32GB?

16GB: Office, coding, light gaming — perfectly fine. 32GB: Video editing, heavy dev (Docker + IDEs), gaming + streaming simultaneously. 64GB only for AI/ML workstations.

BUILD GUIDE
Assembly — Step by Step

First-time builder? Follow these steps exactly. Take your time — rushing causes bent pins and lost screws.

1

Prepare Your Workspace

Clear a large, flat, non-static surface. Remove carpet if possible. Touch your PC case metal to discharge static. Gather all tools: Phillips #2 screwdriver, thermal paste (if not pre-applied), zip ties.

⚡ Anti-static wristband ₹150–₹300 — optional but recommended for first build
2

Install CPU onto Motherboard

Open the CPU socket lever. Align the gold triangle on CPU with the triangle on the socket. Drop in gently — ZERO force needed. Lower the lever to lock. For Intel LGA: align notches. For AMD AM4/AM5: align triangle. CPU should seat with no pressure.

⚠️ NEVER force the CPU — bent pins = dead motherboard. If it doesn't drop in easily, re-align.
3

Apply Thermal Paste + Install CPU Cooler

If your cooler has pre-applied paste (grey pad on bottom), skip this. Otherwise apply a pea-sized dot of thermal paste in the center of the CPU. Mount cooler per its instructions — usually 4 screws in an X pattern. Don't overtighten.

💡 Cooler Master Hyper 212 (₹2,200) or Deepcool AK400 (₹2,800) — excellent budget air coolers
4

Install RAM

Check your motherboard manual for dual-channel slots (usually A2 + B2, or slot 2 + slot 4). Open both clips on the slot. Align the RAM notch with the slot notch. Press down firmly with both thumbs until you hear a click. Both clips should snap closed.

💡 Wrong slot = single channel mode = ~20% slower performance
5

Install M.2 NVMe SSD

Find the M.2 slot on your motherboard. Remove the tiny standoff screw. Insert the SSD at 30° angle, slide in fully, then press down flat and secure with the screw. Some boards have a heatsink — reattach it. This is the one screw you really don't want to lose.

⚠️ Check M.2 slot position — some boards have the slot under the GPU, making it hard to install later
6

Install I/O Shield + Mount Motherboard in Case

Snap the I/O shield (the metal plate with port cutouts) into the back of the case — it clicks in from inside. Install brass standoffs in the correct holes for your motherboard size. Lower motherboard in, align with standoffs and I/O shield, then screw down. Don't overtighten — finger tight + quarter turn is enough.

7

Install PSU and Connect Power Cables

Mount PSU in the bottom of the case (fan facing down/towards vent). Connect: 24-pin main ATX power (large connector, left side of board), 8-pin CPU power (top-left corner of board — critical!), SATA power for any drives. Route cables through grommets.

⚠️ Forgot the 8-pin CPU cable = PC won't power on. Most common first-builder mistake!
8

Install GPU (if using dedicated graphics)

Remove the PCIe slot covers from the back of the case. Push GPU into the top PCIe x16 slot until you hear a click. Screw in the bracket at the back. Connect 6+2 pin power cables from PSU. Most RTX 4060s need 1×8-pin; RTX 4070+ needs 2×8-pin.

9

Connect Case Cables + Install Fans

Front panel connectors (Power SW, Reset SW, HDD LED, Power LED) — check motherboard manual for pin layout. USB 3.0 header (big blue connector) and USB 2.0 headers. Audio header. Fan connectors go to SYS_FAN headers on motherboard.

💡 Front panel pins are fiddly — use tweezers. Even wrong orientation of some pins won't damage anything
10

First Boot — BIOS Check

Connect monitor to GPU (not motherboard if using dedicated GPU). Power on. You should see the BIOS screen. Verify: all RAM detected at correct amount. Go to Memory settings, enable XMP (Intel) or EXPO (AMD) for rated RAM speed. Check all drives detected. Save and exit.

⚠️ No display? Check: monitor connected to GPU not mobo, 8-pin CPU power connected, RAM fully seated, GPU power connected
11

Install Windows / Linux

Create bootable USB (8GB+) using: Windows — Microsoft Media Creation Tool (free, official). Linux — Balena Etcher + ISO. In BIOS, set boot priority to USB. Follow on-screen installation. Install GPU drivers (NVIDIA/AMD) after OS is ready.

💡 Windows 11 Home = ₹0 (functional without activation for years) or buy key from Microsoft Store ₹7,999
🎉 You're Done! After OS install, download GPU drivers (nvidia.com / amd.com), run Windows Update, and test your build with Cinebench R23 (CPU), FurMark (GPU stress test), and HWMonitor to check temperatures. Under load: CPU should be under 85°C, GPU under 83°C.
